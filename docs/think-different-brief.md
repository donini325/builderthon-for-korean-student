# 브리프: 생각과 "팀마다 다르게"를 문장에 (2026-11-06)

대상 레포: `website` (지금 작업 트리, Day 카드에 "하루의 흐름"과 "멘토 보기"가 있는 상태). 정본은 `docs/brand.md`(먼저 읽습니다). 근거는 사용자 2026-11-06: 생각이 강조되어야 하고, 그룹마다 다른 것을 만든다는 점이 강조되어야 한다. 히어로의 캐치프레이즈 두 줄("왜 아직, 손으로?" / "생각부터 하고, 현업에 묻고, 팀마다 다르게 만들어 서로 봅니다.")은 이미 둘을 말하는데, 그 아래 본문과 Day 카드 다섯, 왼쪽 단 셋은 "무엇을 한다"만 말하고 "생각해서", "팀마다 다르게"가 빠져 있습니다. **상자를 더하지 않고 있는 문장을 다시 씁니다.** 11/05 출제사 미팅 전사록의 말("답을 받아 적지 않고 생각하게", "같은 이슈에 똑같은 것이 나오지 않게", "생각이 어떻게 바뀌었는지를 1장으로")이 근거입니다.

## 0. 말하는 법

- "생각"은 동사로 씁니다: 생각해 고르고, 생각으로 설명하고, 생각이 달라집니다. "생각하는 힘"은 11/04 캐치프레이즈의 말이라 남는 것 리드 한 곳에만 둡니다(brand 9장: 한 자리에 한 번).
- "팀마다 다르게"는 같은 이슈를 받고도 병목과 툴이 다르다는 사실로 씁니다. "독창적", "창의적" 같은 형용사는 쓰지 않습니다(brand 5장).
- 바꾸지 않는 것: 캐치프레이즈 두 줄, 코어 둘, 단계 이름 다섯, 세션 제목, 미션 띠, 남는 것 제목 다섯, 하루의 흐름 줄. "빌더" 0, 숫자 약속 0, 줄표와 가운뎃점 0.
