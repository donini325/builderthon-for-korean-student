# 브리프: Day 카드마다 "하루의 흐름" (2026-11-05)

대상 레포: `website` (main 9d54c03). 정본은 `docs/brand.md`(먼저 읽습니다). 근거는 사용자 2026-11-05: 출제사 미팅 전사록(11/05)과 주간 회의 전사록(10/07~11/04)에 있는 행사 진행을 바탕으로, `/crossing`의 Day 카드에 그날이 어떻게 진행되는지가 더 자세히 보여야 한다. 8월 기록(`/2026-08`)의 일정 세부 디자인(시각 띠, ★ 필참 / ○ 선택 표시, 현장과 온라인 표시, 세션 카드)을 참고한다.

## 0. 지금과 8월

| | `/crossing` Day 카드(지금) | `/2026-08` Day 카드 |
| --- | --- | --- |
| 한 줄 | `short` 한 문장 | ★ 필참 / ○ 선택 / ● 놓치면 아까운 + 현장 시각(1PM~4:30PM) |
| 세션 | "세션 Lovable workshop" 한 줄 + 접는 띠(들고 갈 것 / 미션) | 세션 카드(분류, 제목, 시각, 확정, 온라인, 현장, 한 줄) |
| 더 보기 | 없음 | "자세히 보기 →" 모달에 그날의 세션 카드 전부 |
| 하루의 순서 | 없음(시각이 한 군데도 없음) | 시각 띠(runOfShow) |

학생이 지금 카드에서 알 수 없는 것: 몇 시에 어디로 가는지, 출제사 설명이 언제인지, 팀은 언제 어떻게 맺는지, 멘토링과 세션이 하루 안에서 어떤 순서인지, 마지막 날 발표 뒤에 무엇이 있는지.

## 1. 모양 (D1)

안 A(기본): 각 Day 카드 안, 지금의 접는 띠(★ 미션, Day 2에 들고 갈 것)와 같은 문법으로 **"하루의 흐름" 띠** 하나를 더합니다. 펼치면 시각 | 무엇 | 어디 세 칸의 줄 목록이고 필참 줄에는 ★. 폰도 같은 목록. 모달 없음(site-tells 3장: 양을 늘리지 않음, 레이어를 더하지 않음). 시각이 정해지지 않은 줄은 시각 칸을 비우고 순서만 보여 줍니다.

안 B: 8월처럼 "자세히 보기 →"로 모달(EventModal)을 열고 그 안에 시각 띠와 세션 카드. 8월과 같은 부품을 쓰지만 레이어가 하나 늘고, 12월 페이지에서 모달은 등록 폼뿐이라 새 문법입니다.

데이터: `data/naru.ts` `december.stages[n].flow: { time?: Phrase; what: Phrase; where?: Phrase; must?: boolean }[]`. 시각은 KST "10:00" 꼴 문자열, 날짜는 `dayOffset`이 이미 있음. 화면 글은 KO/EN 둘 다.
